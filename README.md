# Agentic AI Projects - 7th Semester (2026-27 Batch)

This is a static, responsive portfolio website displaying exactly 15 Agentic AI projects.

## Editing the Links

To update the 15 placeholders with actual links, titles, and descriptions, open `script.js` and modify the array at the top of the file under the `// PASTE PROJECT LINKS HERE` comment.

Example of how to edit:
```javascript
const projects = [
  {
    title: "Real AI Project 01",
    team: "TEAM: Alpha",
    url: "https://example.com/project-1"
  },
  // Add exactly 15 objects here...
];
```

## Deployment

This site is built with plain HTML, CSS, and Vanilla JS, which means it requires no build step.
It is deployed directly via GitHub Pages from the `main` branch.
